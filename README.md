## Undergraduate thesis

I built an Android–Windows speculative decoding system. The phone runs Qwen2.5-0.5B to propose tokens, and the PC runs Qwen2.5-7B to verify them. In a local-network experiment generating about 1,000 tokens, the system sustained **14.0 tokens/s**: **93.5% higher** than running the 7B model on the phone alone and **94.5% of the throughput** of two-process speculative decoding on Windows.

See the [Android–Windows project and phone demo](https://github.com/Doffin-azure/Android-Speculative-Inference) and the [desktop two-process demo](https://github.com/Doffin-azure/spec-split-demo-project).
